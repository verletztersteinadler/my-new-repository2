# KOTLY.SU — каталог LAVART

Одностраничный независимый справочник промышленных котлов. Инженерный проект на добровольных началах, не сайт завода и не витрина коммерческого оператора.

Главная сразу показывает серии, фильтры и форму «Запросить КП». Техническое задание лежит в `attachments/TZ_KOTLY_SU_2026-11-13.docx`.

```bash
npm install
npm run dev
```
