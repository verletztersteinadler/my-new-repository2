# kotly.pro | Промежуточная выгрузка, партия 03

**Это не полный каталог.** Архив содержит только текущую восстановленную партию. Результаты первых двух проходов сюда не включены. Между партиями возможны пересечения; для импорта потребуется сверка по производителю, серии, обозначению и исполнению.

1948 подтверждённых строк моделей или явно перечисленных изготовителем типоразмеров по 29 брендам. Ещё 9 брендов в этой партии имеют только подтверждённые семейства либо статус без точной таблицы. Все 310 карточек сайта были открыты в предыдущих проходах, но извлечение моделей по всем производителям не завершено.

- `models.csv` — строки отдельно от кодов и статусов вариантов; `source_id` → `sources.csv`.
- `coverage.csv` — только бренды этой партии, не весь каталог.
- `gaps.csv` — подтверждённые диапазоны, отсутствующие таблицы и ограничения, не строки моделей.
- `manifest.json` — отклонённые записи и контрольные числа.

Пустое поле означает отсутствие подтверждённого значения, а не ноль. `equivalent_evaporation_kg_h` — эквивалентная, а не рабочая паропроизводительность. Отдельно помечены проектные, архивные, сертификатные и региональные исполнения. Технические значения не заменяют паспорт котла. Исходные документы не копировались.
