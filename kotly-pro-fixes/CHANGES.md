# Исправления R22 — аудит от 28.11.2026

Файлы в этой папке заменяют одноимённые файлы внутри `kotly-pro.zip`.
Сам zip не обновлялся: бинарник нельзя надёжно перезаписать через API одним файлом.
Наложите эти файлы поверх распакованного zip и соберите его заново.

## Что исправлено

1. **Дубли http/www в индексе (SEO, горящий баг).**
   Все четыре варианта хоста (`http://`, `https://`, c `www` и без) отдавались
   с кодом 200 без редиректа, из-за чего каждая страница умножалась на четыре.
   - `deploy/nginx-kotly-pro.conf` — конфиг для хостинга: 301 http→https,
     301 www→без-www, HSTS. Поднять на сервере kotly.pro.
   - `vercel.json` — те же заголовки (HSTS, nosniff, Referrer-Policy)
     и 301 для страниц без слэша на деплое Vercel.

2. **Canonical на каждой странице.**
   Раньше canonical был только на статических страницах хостинга, у SPA-роутов
   его не было вовсе. Теперь у всех маршрутов (`/`, `/manufacturers/:slug`,
   `/politika`, `/soglasie`) canonical указывает на `https://kotly.pro/...`
   через новую константу `SITE_ORIGIN` в `src/data/catalog.ts`.

3. **noscript-фолбэк.**
   Каталог рендерится на клиенте; без JavaScript пользователь и краулер
   получали пустую страницу. В `src/routes/__root.tsx` добавлен noscript-блок
   с понятным сообщением.

## Проверено

- `node scripts/catalog-check.mjs` — ok (дублей slug и оборванных карточек нет).
- Тесты `scripts/*.test.mjs`, падающие до и после правок, падают из-за
  отсутствующих в zip платформенных файлов `.grok/` и `node_modules`,
  правки их не трогают.
