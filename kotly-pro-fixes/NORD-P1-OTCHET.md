# НОРД — P1, карточка М070

Сверка 28.11.2026. Сайт доступен: **kotelnord.ru** (WordPress). Изготовитель: ООО «НОРД», завод по производству водогрейных котлов, г. Череповец. Карточки бренда в исходном архиве не было — файл создан с нуля. Контрольной группы в листе «Контроль серий» нет.

## Что сделано

Файл `src/data/nord.ts`: **4 серии, 67 типоразмеров**, категории hw115 / hw170 / auto (горелки).

- **НОРД-2Х (КН-2.15)** — двухходовые жаротрубные, hw115: 18 типоразмеров 100–2000 кВт из руководства 04.05.02.15.0321 РЭ, 0,6 МПа, вода до 115 °C, газ/СУГ/дизель, сталь 09Г2С, КПД 91,8–94,9 % по типоразмерам.
- **НОРД-3Х (КН-3)** — трёхходовые жаротрубные, hw170: 23 типоразмера 1000–20000 кВт. Ряд одинаков во всех четырёх руководствах (КН-3.15-10, КН-3.40, КН-3.50, КН-3.70), подтверждено по таблицам 1 каждого РЭ. Исполнения: 1,0 МПа / 115 °C (тип БКН-3.15-10В), 0,85 МПа / 140 °C, 1,0 МПа / 150 °C, 1,6 МПа / 170 °C. Топливо: газ, пропан-бутан, дизель, тяжёлый мазут. КПД 90,3–95,5 % по типоразмерам и исполнениям.
- **Горелки НОРД В** (моноблочные, auto) — газовые и дизельные ряды моделей 30–18000 (мощность 48–17500 кВт), комбинированные ГД 150–18000 (160–17500 кВт), новинка 2025 года: 26 обозначений модельных групп (Г/Д/ГД).
- **Горелки НОРД двухблочные** (auto) — 10–80 МВт, газ/дизель/комбинированные; раздел сайта в разработке, ряд не опубликован.

Проверки: `catalog-check: ok`, импорт-тест файла пройден (4 серии, 67 типоразмеров, 9 документов).

## Источник типоразмеров

На сайте типоразмерных таблиц нет. Ряды взяты из руководств по эксплуатации с сайта (парсинг PDF самодельным экстрактором: у сайта корректные PDF, pypdf в окружении недоступен). Дизельные исполнения КН-2.15 марок 560/660/870/1360/1530/1740 имеют мощность на 1 кВт выше (561/661/871/1361/1531/1741) — в ряд внесены газовые значения.

## Расхождения (зафиксированы в extra серий)

- Нижняя граница НОРД-2Х: сайт «от 75 кВт», титул РЭ «120–2000 кВт», таблицы РЭ начинаются со 100 кВт — в карточке взят ряд таблиц (100–2000).
- Давление 0,6 МПа для НОРД-3Х заявлено сайтом («от 0,6 до 1,6 МПа»), но ни одно из четырёх открытых руководств его не подтверждает; файл «РЭ КН-3.15.pdf» по ссылке отдаёт 404-страницу.
- Индекс моделей горелок НОРД В (30–18000) не равен киловаттам (48–17500 кВт), мощность по моделям не расписана — в размерах только обозначения, мощность null.
- Страницы gorelki-mono и gorelki-mono-v идентичны по содержанию.

## Не включено в серию котлов

- **ГРПШ-НОРД** (бытовой газорегуляторный пункт) — не котёл, в карточку не внесён.
- **Паровые котлы**: реестр упоминает «водогрейные, паровые котлы», но на сайте паровых котлов нет — в карточке паровых серий нет. Для каталога это отметить при публикации карточки бренда.
