## Решения и расхождения

1. **Нумерация моделей.** Паровые серии (BHP-EN, BHP-T, BLP, SB/V): индекс модели = кг/ч пара (SB/V — в тоннах: SB/V 3 = 3 000 кг/ч, подтверждено техпаспортом). ASB/ASA, XV/AS, ODE C/V, Trinox: индекс = тыс. ккал/ч (Mcal/h); полезная мощность в кВт указана в описании типоразмера и в полях диапазона. SupeRac/Trispace/Ecocond/MiniRac: индекс ≈ кВт.
2. **Серии 2F и TS** — котлы из двух корпусов с двойной топкой: лист производительности даёт фактическую мощность (2F: удвоенную относительно однотопечной модели; TS: собственную таблицу). В карточке мощность по листу, индекс сохранён.
3. **SupeRac C / P / AR-C / AR-P** — варианты поставки того же ряда (5 частей / полностью разобранный) для узких проёмов; отдельные карточки не создавались, упомянуты в extra SupeRac и SupeRac AR.
4. **XV/AS:** страница сайта указывает 9,8 бар («больше по заказу»), техпаспорт rev05-2025 (имя файла «12bar») — 12 бар; зафиксировано в pressureNote.
5. **OV** — паровой испаритель с обогревом термомаслом (работает в паре с ODE), прямого сжигания нет: fuels: [], без типоразмеров (ряды производителем не публикуются).
6. **Фактическое совпадение ряда Schuster SCHD (116–5 815 кВт) с I.VAR ODE C** — оба итальянских производителя дают идентичные значения; данные зафиксированы по каждому из своих источников независимо.
